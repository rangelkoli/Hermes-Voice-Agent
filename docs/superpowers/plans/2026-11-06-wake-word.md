# On-Device Wake Word Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nothing is transcribed or sent anywhere until a local detector hears the wake phrase.

**Architecture:** While asleep, frames go only to an on-device keyword spotter and a short ring buffer. When the phrase fires, the buffer and later frames flow into the existing segmenter, so "Hey Hermes, open the logs" works in one breath. The phrase is stripped from the transcript. The gate closes after one command, or after 8 quiet seconds.

**Tech Stack:** Existing stack plus `sherpa-onnx` and `sentencepiece`. Wheels resolve for macOS arm64, Linux x86_64, and Linux aarch64 on Python 3.13.

**Spec:** Requested in conversation. Decisions below.

## Decisions

- Wake is on by default with phrase `hey hermes`. `--wake "<phrase>"` changes it. `--open-mic` restores the old every-utterance behavior.
- The old text-only `--wake` filter is replaced. `apply_wake` is removed.
- Detection is on-device. The ring buffer is 1500 ms, so up to that much audio before the phrase ends can go to transcription after a wake.
- One wake gives one command. No follow-up window.
- Approvals stay keyboard only.

## Global Constraints

- While asleep, no audio reaches the segmenter, the transcriber, or any network call.
- Audio is never written to disk.
- All tests run with no network, mic, Gemini, or Hermes.
- Do not read any `.env` file.
- macOS and Linux behave the same.

## Verified Facts

From a spike on 2026-11-06 with Python 3.13, `sherpa-onnx` 2.0.1.

- Model: `https://github.com/k2-fsa/sherpa-onnx/releases/download/kws-models/sherpa-onnx-kws-zipformer-gigaspeech-3.3M-2024-01-01.tar.bz2`, 17,626,723 bytes, SHA-256 `f170013b4716e41b62b9bfd809687c207cef798ef9bc6534d524e17af9b6561a`.
- It unpacks to `sherpa-onnx-kws-zipformer-gigaspeech-3.3M-2024-01-01/` with `tokens.txt`, `bpe.model`, `encoder-epoch-12-avg-2-chunk-16-left-64.onnx`, `decoder-epoch-12-avg-2-chunk-16-left-64.onnx`, `joiner-epoch-12-avg-2-chunk-16-left-64.onnx`.
- `sherpa_onnx.text2token` needs `pypinyin`. Do not use it. Tokenize with `sentencepiece.SentencePieceProcessor(model_file=<bpe.model>).encode(phrase.upper(), out_type=str)`.
- The keywords file holds one line: `" ".join(tokens) + " @" + phrase.upper().replace(" ", "_") + "\n"`.
- Working API:
```python
spotter = sherpa_onnx.KeywordSpotter(tokens=..., encoder=..., decoder=..., joiner=...,
                                     keywords_file=..., keywords_threshold=0.25, num_threads=1)
stream = spotter.create_stream()
stream.accept_waveform(16000, float32_samples_scaled_to_plus_minus_1)
while spotter.is_ready(stream):
    spotter.decode_stream(stream)
    if spotter.get_result(stream):   # non-empty on a hit
        spotter.reset_stream(stream)
```
- Detection trails the end of the phrase by about 0.4 s. That is why the ring buffer exists.

## Review Focus

1. **One breath:** "Hey Hermes, open the logs" keeps its first words, and Hermes receives `open the logs`.
2. **Phrase, pause, command:** "Hey Hermes" then "open the logs" two seconds later still works. A transcript that is only the phrase keeps the gate open.
3. **Room talk while asleep:** no frame reaches the segmenter. A transcript finishing after the gate closed is dropped.
4. **Model download fails, or its hash is wrong:** a plain message and exit 1 before the UI. Nothing partial stays behind.
5. **Mute, mic loss, and speech playback:** the gate closes and the spotter resets, so old audio cannot fire it.

**Interfaces:**
- In `hermes_voice.wake`:
  - `WakeError(Exception)`: message shown to the user as-is.
  - `ensure_model(root: Path | None = None, download: Callable[[str, Path], None] | None = None) -> Path`: returns the model directory. Default root is `$XDG_CACHE_HOME/hermes-voice/wake`, else `~/.cache/hermes-voice/wake`. Skips work if `tokens.txt` exists. Default `download` uses `urllib.request.urlretrieve`.
  - `WakeSpotter(phrase: str, model_dir: Path, threshold: float = 0.25)`: `.feed(frame: bytes) -> bool`, `.reset() -> None`. `sherpa_onnx` and `sentencepiece` are imported inside the constructor.
  - `WakeGate(spotter, ring_ms: int = 1500, window_s: float = 8, clock=time.monotonic)`
    - `.awake: bool`
    - `.feed(frame: bytes) -> list[bytes]`: frames for the segmenter. Asleep returns `[]`, except on a hit, which returns the ring contents ending with this frame.
    - `.touch() -> None`: restarts the 8 second window.
    - `.expire(busy: bool) -> bool`: closes if the window passed and `busy` is false; returns True if it closed.
    - `.sleep() -> None`: closes, clears the ring, resets the spotter.
- In `hermes_voice.stt`: `strip_wake(text: str, phrase: str) -> str` replaces `apply_wake`.
- `VoiceApp(..., wake: str | None = None, gate: WakeGate | None = None)`. New status `waiting`.
- CLI: `--wake` default `hey hermes`, `--open-mic`, `--wake-threshold` (float, default 0.25).

- [ ] **Step 3: Implement `wake.py` and `strip_wake`**

`ensure_model`: download to a temp file inside `root`, check SHA-256, unpack with `tarfile.open(..., "r:bz2").extractall(root, filter="data")`, remove the archive. On any failure remove the temp file and any partial model directory, and raise `WakeError` naming what to do, including that `--open-mic` needs no model.

`WakeSpotter`: write the keywords line to a temporary file used only for the constructor, then delete it. If the spotter needs the file later, keep it and delete on exit, and say so in the report. Convert frames with numpy.

`strip_wake`: build a case-insensitive regex from the phrase's words joined with `\W+`. If the phrase starts with `hey `, make that word optional. Take everything after the last match, strip surrounding punctuation and spaces. No match returns the text unchanged, since the detector already heard the phrase.

- [ ] **Step 4: Wire `VoiceApp`**

All gate calls happen under `_audio_lock`.

- Capture: with a gate, pass the frame through `gate.feed`. On the asleep-to-awake change, reset the segmenter, call `bell` on the UI thread, and sync status. Push each returned frame into the segmenter. When an utterance finishes, call `gate.touch()`. Call `gate.expire(busy=segmenter.in_speech or utterances are queued or being transcribed)` and sync status when it closes.
- The level meter keeps working while asleep. It is local only.
- `on_transcript`: with a gate, drop the text if the gate is not awake. Otherwise `strip_wake`. If the result is empty or `is_noise`, return and stay awake. Otherwise `gate.sleep()` and send as usual. Without a gate, behave as open mic does now.
- Close the gate on mute, on mic loss, and when speech playback starts.
- Status priority: add `waiting` as the lowest, used when a gate exists and is asleep. Awake with nothing happening is `listening`. Show the header as `WAITING FOR "HEY HERMES"`, using the phrase, while `.status` stays `waiting`.
